# 润网业务系统 V2

业务报价 → 表单填写 → 手续审核。

共享演示入口：https://runwell-demo.shipstatic.com/#/forms 。两人的代码合并到 `main` 后，由 GitHub Actions 检查并自动发布免登录演示版。演示使用虚构资料，模板与生成历史各自保存在浏览器。详见 [演示发布说明](docs/demo-publishing.md)。

默认模式为可运行骨架：报价和审核提供占位入口；表单填写包含表单生成、历史记录、套餐模板管理。客户字段禁用，仅供布局预览。尚未连接数据库或实现登录、保存、上传、模板匹配、Word生成和审核。

## 本地运行

需要 Node.js 22+，无第三方依赖，无需安装包。

```powershell
node backend/server.mjs
```

浏览器访问 http://127.0.0.1:3000 ，Ctrl+C停止。端口冲突时先设置 `$env:PORT=3001`。仅监听本机，不用于生产。

```powershell
node --test tests/*.test.mjs
```

如已安装npm，可使用npm run dev和npm test。

## 目录

- frontend/app.js：路由与导航。
- frontend/modules/：工作台与表单页面。
- frontend/lib/：公共请求、转义工具。
- backend/app.mjs、server.mjs：应用及启动入口。
- backend/modules/：分类、表单、报价、审核模块。
- docs/：范围、接口和双人协作约定。
- tests/：隔离检查。

本地Node.js服务用于预览与接口骨架，正式后端、数据库和Word引擎待确认。旧项目和数据未迁移，未部署。

## 表单验收版（Issue #1）

在项目目录运行以下命令，打开终端显示的本机地址，进入“表单填写”。选用启动终端中员工 A、员工 B 或模板管理员的临时口令。仅使用虚构资料。

```sh
node backend/server.mjs --forms-preview
```

此模式需要 Node.js 22.13+ 和 Python 3.9+，无需安装第三方包。Windows 默认调用 python，其他系统使用 python3；可设置 FORMS_PYTHON 为解释器路径。SQLite 和生成的内容保存在 .forms-preview 目录。重启服务保留记录并更换口令。默认启动方式仍可查看原始骨架。

1. 员工选“商务专线 → 测试版（不带语音） → 新装 → 测试套餐 A 或 B”，点“匹配模板”。填写虚构资料，确认生成后可立即下载 Word，也可从个人历史记录重新下载。
2. 管理员在模板管理中下载样表和查看占位符映射，选择适用套餐后上传新版本并启用。两个版本同时启用时，员工需明确选择。停用或新增候选后，旧的匹配结果需重新确认。
3. 切换到员工 B，应无法查看员工 A 的记录。管理员权限只增加模板管理能力。
4. 模板限 512 KiB，支持基础段落、直接格式和简单表格。占位符写作 {{field}}，可跨同段文字单元。图片、页眉页脚、样式引用、宏、附件、外链等暂不支持。额外必填资料使用 extra_ 前缀。测试样表中企业地址、账单地址、银行字段、付款勾选独立映射。

正式套餐、正式 Word 版式及员工登录和数据库方案仍待双方确认。测试套餐和本机口令仅用于联调。验收测试使用独立临时库，不读取旧项目或客户数据。
